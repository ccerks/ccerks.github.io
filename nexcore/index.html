The enterprise backbone for SaaS builders.

A highly scalable, multi-tenant B2B backend architecture built with FastAPI, PostgreSQL, and deployed on AWS ECS Fargate.

# Create a new isolated tenant schema & setup billing
curl -X POST "https://nexcore-api.ccerks.com/v1/tenants" \
  -H "Authorization: Bearer $SUPERADMIN_TOKEN" \
  -d '{"name": "Acme Corp", "slug": "acme"}'

✔ Tenant 'Acme Corp' provisioned successfully.
✔ PostgreSQL schema 'tenant_acme' created.
✔ Stripe Customer & Billing initialized.
